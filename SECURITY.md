# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
| Older versions | No |

## Reporting a vulnerability

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/S3bx0/Dane-Meteo-Stacje/security/advisories/new).
Do not open a public issue and do not include NOAA tokens or other credentials in reports,
logs, screenshots, or reproduction data.

Include the affected version, impact, reproduction steps, and a minimal proof of concept when
possible. The maintainer will acknowledge a report within 72 hours, provide status updates as
the investigation progresses, and coordinate disclosure after a fix is available.

Security fixes are validated with the normal CI, CodeQL, dependency audit, package smoke test,
and relevant regression tests before release.
